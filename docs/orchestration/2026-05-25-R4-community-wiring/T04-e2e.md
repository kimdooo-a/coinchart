## 2. 배경 / 발사 타이밍

R3에서 board(`ƒ`)·news(`ƒ`)·coin(`● SSG+ISR 6종`)이 SSR로 전환됐고, R4/T02가 게시글 비추·댓글 추천을 결선한다. 본 터미널은 이 흐름을 E2E로 검증한다.

⚠️ **발사 전 권장 선행**: T01 런북대로 `supabase db push`가 끝나고(추천/댓글 RPC·테이블 적용), T02 wiring이 머지돼 있어야 추천/비추/댓글 플로우가 실제로 통과한다. 선행이 안 됐다면 — **시나리오·Playwright 코드 작성 + SSR 렌더·내비게이션·필터까지만 실행 검증**하고, 추천/비추/댓글 토글은 `test.skip` 또는 "DB 적용 후 재실행" 으로 표시한다 (hard-fail 금지).

## 4. 작업 목표

> **`/kdye2e` 스킬을 사용**한다 (시나리오 도출 → 실행 → 실패 진단 → 개선 자동화). 스킬이 프로젝트 레퍼런스·핸드오버를 분석해 시나리오를 생성한다.

### 핵심 시나리오 (최소 커버리지)
1. **게시판 SSR + 내비게이션**: `/board/free`·`/market`·`/info` 목록 렌더 → 글 클릭 → 상세(`/board/[slug]/[postId]`) 진입 → 본문·댓글 SSR 노출 확인.
2. **게시글 추천/비추**: 상세에서 추천 클릭 → 카운트 증가, 비추 클릭 → **dislikeCount 실값 표시**(T02 결선 검증, 가짜 0/1 아님). 재클릭 토글 취소.
3. **댓글**: 댓글 작성(익명 닉/비번) → 목록 반영 → 댓글 ThumbsUp 클릭 → likeCount 증가(T02 결선). 추천순 정렬 반영.
4. **뉴스 SSR + 4차원 필터**: `/news` 렌더 → 코인/카테고리 필터 → 목록 갱신.
5. **코인룸 SSG/ISR**: `/coin/btc`(및 6종 중 일부) 렌더 → 시세·게시글·뉴스 탭 노출.
6. **관리자 공지**: `/admin/board`에서 is_notice 토글(R3/T06) → 목록 상단 공지 노출 (인증 필요 시 시나리오에 전제 명시, 미가능 시 skip+메모).

### 산출물
- `e2e/` (신규 디렉토리) — Playwright 테스트 파일들 (`community-board.spec.ts` 등)
- `docs/e2e/R4-scenarios.md` — 시나리오 명세 + 실행 방법 + 통과/스킵 현황
