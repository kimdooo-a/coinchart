**주요 논의**:

1. **정체성 피벗 (세션 6)** — 사용자 요청: "코인판 사이트처럼 정보공유의 장을 만들고 싶다." → 4가지 핵심 결정:
   - 정보 공유 주체: **유저 커뮤니티** (코인판식)
   - AI 차트 분석: **부가 기능**으로 격리 ("도구" 메뉴), URL은 그대로
   - 뉴스 분류: **AI API 미사용**, 룰베이스 키워드 사전 + 점수
   - 디자인 톤: **네이버 스타일** (흰 배경, 정보 밀도, 표 위주)

2. **권한 모델·MVP 범위** — 익명+회원 혼용 (코인판식 IP 앞 2옥텟 마스킹), MVP는 4개 페이지(메인/게시판/상세+작성/뉴스+코인룸)

3. **Stitch 시안 분석 (세션 7 진입 시)** — 시안 HTML 직접 검사로 정확 매핑:

   - 시안 미국식 색상(녹=호재, 빨=악재) → 한국식(빨=호재, 파=악재)으로 강제 적용
