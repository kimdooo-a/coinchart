### [4] lightweight-charts v5 ColorType enum 이슈

**논의**:
- spec은 `background: { type: 'solid' as const, color: '#ffffff' }` 코드 그대로 작성하도록 안내
- 실제 작성 후 `npx tsc --noEmit` 실행하니 `TS2322: Type '"solid"' is not assignable to type 'ColorType | undefined'` 에러 발생
- 원인: lightweight-charts v5.0.9에서 `ColorType`이 string literal union이 아닌 **enum**으로 강화됨
- 해결: `import { ColorType, type DeepPartial, type ChartOptions }`로 enum 값을 named import하고 `type: ColorType.Solid`로 교체

**결론**: spec과 다른 코드(ColorType.Solid)로 작성. 재사용 가치 있는 패턴이므로 별도 solutions 문서로 기록.
