## 0. 한 문장 정체성

> **"한국 투자자가 모이는 코인·주식 정보 공유 커뮤니티 — 자유 토론과 큐레이션 뉴스, 그리고 (부가 도구로서) AI 차트 분석 룸이 한 자리에 있는 곳."**

코인판(자유게시판 중심) × 네이버(정보 밀도·표 형식·사이드바 위젯) × ChartMaster(기존 AI 차트 분석)의 하이브리드.

## 2. 정보 아키텍처 (IA)

### 2-1. 메뉴 구조 (피벗 후)

```
[로고] | 베스트  자유게시판  시세토론  정보공유  뉴스  ┊  코인룸 ▼  도구 ▼  ┊  [검색] [로그인/글쓰기]

코인룸 ▼  : BTC / ETH / XRP / SOL / 알트코인 / 김치프리미엄
도구 ▼    : 차트분석(코인) / 차트분석(주식) / AI시그널 / 마켓무드 / 캘린더 / 워치리스트 / 보안메모
```

- 기존 5개 메뉴 그룹(`코인/주식/정보/서비스/블로그`) → **5개 라이트한 메뉴 + 2개 드롭다운**으로 단순화
- "코인" "주식" 같은 추상 묶음 폐기 → "어디서 무엇을 하는지"가 메뉴 라벨에 그대로 드러나게
- 블로그는 메뉴에서 제거하고 "정보공유 → 공식글" 카테고리로 흡수 (또는 푸터에 잔존)

### 2-2. 게시판 분류 (1차)

| 게시판 | URL | 작성 권한 | 특징 |
|--------|-----|----------|------|
| **자유게시판** | `/board/free` | 익명·회원 | 일상·잡담·뉴스 반응 |
| **시세토론** | `/board/market` | 익명·회원 | 차트·진입가·전략 토론 |
| **정보공유** | `/board/info` | 익명·회원 | 분석글·뉴스 정리·자료 |
| **코인룸 (BTC)** | `/coin/btc` | 익명·회원 | BTC 전용 토론·시세·뉴스 통합 |
| **코인룸 (ETH 외)** | `/coin/{symbol}` | 익명·회원 | 코인별 동일 구조 |
| **공식글 (블로그)** | `/blog` | 어드민 | 운영자 심층 글, 공지 |

### 2-3. 페이지 인벤토리

| 카테고리 | 페이지 | 신규/유지/리디자인 |
|---------|-------|------------------|
| 메인 | `/` (홈) | **리디자인** |
| 게시판 | `/board/{free,market,info}` | **신규** |
| 게시판 | `/board/{slug}/{post-id}` (상세) | **신규** |
| 게시판 | `/board/{slug}/write` (작성) | **신규** |
| 코인룸 | `/coin/{symbol}` | **신규** |
| 뉴스 | `/news` | **리디자인** (기존 카드형 → 표+사이드바형) |
| 도구 | `/analysis`, `/stock`, `/signal`, `/market` 등 | 유지 (메뉴 위치만 이동) |
| 블로그 | `/blog`, `/blog/{slug}` | 유지 (URL은 `/blog`, 메뉴는 "공식글"로) |
| 부가 | `/portfolio`, `/secure-memo`, `/watchlist`, `/calendar` | 유지 (도구 드롭다운) |
| 인증 | `/auth/*` | 유지 |
| 정책 | `/terms`, `/privacy`, `/contact` | 유지 |

## 3. 작성 권한 모델 (코인판식)

### 3-1. 사용자 유형

| 유형 | 식별 | 작성 | 수정/삭제 | 표시 닉네임 | 표시 IP |
|------|------|------|----------|-------------|---------|
| **익명 게스트** | 작성 시 닉네임+비밀번호 입력 | O | 비밀번호 일치 시 | 입력값 | IP 앞 2옥텟 (예: 211.34.*.*) |
| **회원** | Supabase Auth (이메일/구글/카카오) | O | 본인 글 자유 | 프로필 닉네임 (고정) | 표시 안 함 |
| **어드민** | role='admin' | O | 모든 글 | 닉네임 + 🛡 뱃지 | 표시 안 함 |

### 3-2. DB 스키마 추가 필요

## 4. 뉴스 분류 강화 (룰베이스 "AI 흉내")

> **AI API 미사용 결정**. 키워드 사전 + 점수 합산 + 시간 감쇠로 "AI처럼 보이는" 결과를 만든다.

### 4-1. 분류 차원

| 차원 | 값 | 분류 방법 |
|------|-----|---------|
| **코인 태그** | BTC/ETH/XRP/SOL/도지/알트/주식/일반 | 제목·본문에 코인명·티커·한글명 매칭 (다중 매칭 시 빈도 우선) |
| **카테고리** | 시장동향 / 규제 / 기술·업데이트 / 거래소 / 온체인·고래 / ETF·기관 / 알트코인 / 매크로 | 카테고리별 키워드 사전 (예: 규제 = `SEC, 규제, 금지, 승인, 허가, 가이드라인, 제재, 과세, 세금...`) |
| **호재/악재** | 호재 / 악재 / 혼조 / 중립 | 양·음 키워드 사전 + 가중치 점수 (예: `급등 +3, 사상최고 +5, 폭락 −5, 해킹 −5, 승인 +4`) → 합산 부호로 분류 |
| **중요도** | 1~10점 | 발행 시간 감쇠 + 매체 가중치(주요 매체 +) + 키워드 가중치 합산 |

### 4-2. 룰베이스 구현 위치

- `lib/news/classifier.ts` (신규) — 키워드 사전 + 분류 함수
- `lib/news/keyword-dict.ts` (신규) — 키워드 사전 데이터
- `app/api/admin/news-crawl/route.ts` (수정) — 분류 함수 호출하여 sentiment·category 채움
- DB 스키마 `news` 테이블에 `category`, `importance_score` 컬럼 추가 마이그레이션

이 부분은 디자인 의뢰서와는 별개로 **백엔드 작업**이라, 디자인 의뢰서에는 "분류 결과 4차원이 화면에 어떻게 노출되는가"만 명시.

## 5. AI 차트 분석의 새 위치

기존 `/analysis`, `/stock`, `/signal`, `/market` 등 모든 분석 페이지는 **유지**. 단:

- **메뉴 위치**: 상단 "도구" 드롭다운에 격리
- **홈 노출**: 홈 페이지 사이드바 또는 하단 영역에 작은 위젯으로 (메인 영역은 베스트글)
- **코인룸 통합**: `/coin/btc` 같은 코인별 룸의 상단에 "이 코인의 차트 분석 보기" 링크 카드 1개 노출 → 클릭 시 `/analysis/btc`로
- **블로그/게시글에서 임베드**: 게시글 작성 시 "차트 분석 결과 임베드" 버튼 (선택, 2차)

기존 차트 분석 코드는 한 줄도 안 건드림. URL과 컴포넌트는 그대로.

## 6. 디자인 톤 — 네이버 스타일

### 6-1. 키워드

- **밝은 배경**: 흰색(#FFFFFF) 메인, 라이트 그레이(#F5F6F8) 사이드바·구분
- **타이트한 정보 밀도**: 한 화면에 많은 정보. 카드 그림자·여백 최소화
- **표 + 리스트 위주**: 게시판은 글 제목·작성자·시간·조회·추천이 한 줄 표
- **포인트 컬러 1~2개**: 메인 컬러(블루 계열) + 호재(레드)/악재(블루) 강조
- **사이드바 위젯**: 인기글 / 시세 위젯 / 광고 영역(추후) / 실시간 검색어
- **한글 폰트**: Pretendard 또는 Noto Sans KR

### 6-2. 다크모드

1차에서는 **라이트 모드만**. 다크는 v2.1에서 토글로 추가 (변환 가능한 토큰 구조로 설계).

## 8. 합의 후 작업 순서

1. **이 문서 합의** ← 지금 단계
2. `docs/design-brief/00~05.md` 작성 (Stitch 의뢰서) ← **이 세션에서 진행**
3. 사용자가 Stitch에서 디자인 받음 (외부 작업)
4. 디자인 결과 도착 후 → 백엔드 작업: 커뮤니티 DB 마이그레이션 + API + 페이지 구현
5. 뉴스 룰베이스 분류 로직 구현
6. 메뉴 구조 변경 (`global-header.tsx`)
7. AI 분석 페이지들을 "도구" 드롭다운 아래로 정리 (URL 유지)

## 9. 명시적으로 결정한 사항 (재확인용)

- ✅ 정보 공유 주체: **유저 커뮤니티** (코인판 방식)
- ✅ AI 차트 분석: **부가 기능**. 메인 자리 양보.
- ✅ 뉴스 분류: **AI API 미사용**. 룰베이스 "AI 흉내".
- ✅ 디자인 톤: **네이버 스타일** (흰 배경, 정보 밀도, 표 위주, 사이드바 위젯)
- ✅ 작성 권한: **익명+회원 혼용**
- ✅ MVP 5개 페이지: 홈 / 게시판 리스트 / 게시글 상세+작성 / 뉴스 / 코인룸
