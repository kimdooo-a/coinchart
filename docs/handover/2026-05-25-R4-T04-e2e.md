## 5. 발견 사항 / 진단 (회귀 0건)

### (a) S-AD1 최초 실패 → 테스트 기대 정정 (앱 버그 아님)
- **현상**: 비로그인 `/admin/board` 접근 시 "접근 권한 없음" 게이트가 아니라 `/auth/login`("Welcome Back")으로 이동.
- **진단**: `middleware.ts:69` `protectedPaths`에 `/admin` 포함 → 비로그인 시 `:77` `/auth/login` 리다이렉트(**정상 라우트 보호**). admin/board 클라 컴포넌트의 "접근 권한 없음"은 *로그인했으나 비관리자*일 때의 2차 방어선이라 비로그인 E2E로는 도달 불가.
- **조치**: 테스트를 실제 동작(`/auth/login` 보호 리다이렉트 검증)으로 수정. **앱 코드 무수정**(격리 준수). → 재실행 통과.

### (b) SSR graceful 폴백 확인 (정상)
- board/news/coin 서버 모듈은 DB 테이블 부재 시에도 `data ?? []`로 빈 목록을 렌더("이 카테고리에 아직 글이 없습니다"/"조건에 맞는 뉴스가 없습니다"/"아직 글이 없습니다"). SSR·내비·필터 시나리오가 빈 DB에서도 통과하는 근거.

### (c) 코인룸 6종 SSG 프리렌더 + dynamicParams=false 404 확인
- altcoin/kimp 집계형 포함 6종 모두 탭리스트·핵심지표 렌더. 목록 외 슬러그(`/coin/not-a-coin`)는 404.

**실제 애플리케이션 회귀/버그: 없음.**
