## 1. 요약

천장 4영역에 대해 (a) 아이콘 전용 버튼 `aria-label`, (b) 폼 `label`↔`input` 의 `htmlFor`/`id` 연결, (c) 라이트 배경 위 대비 부족 회색(`text-gray-400`) → `text-on-surface-variant` 토큰 교체를 수행했다. 의미색·그라데이션 위 흰글씨·다크 컨텍스트(코드블록/드롭다운) 회색은 보존했고, `CommunityTabs`/`Pagination`은 손대지 않았다. tsc·build·grep 검증 모두 PASS.

## 7. 검증 결과 (4종 모두 PASS)

1. **타입체크** `npx tsc --noEmit` → exit 0 (에러 0).
2. **빌드** `npm run build` → 성공(전체 라우트 테이블 + 범례 정상 출력).
3. **회색 잔여 grep** `text-(gray|slate|zinc)-400` (천장 4영역) → 2건 잔여, **모두 의도적 보존**(BlogPostContent 다크 코드블록, ColorPicker 다크 드롭다운). 라이트 컨텍스트 위반 0.
4. **aria-label/연결 재확인** → aria-label 6건·htmlFor↔id 9쌍 grep으로 실제 추가 확인.
5. **보존 확인** → 의미색·그라데이션 흰글씨·CommunityTabs/Pagination 미변경 확인.

## 8. 잔여 위험 / 후속 권고

- **에디터 다크 잔재(텍스트 외)**: `EditorToolbar`의 `Divider`(`bg-white/10`)·뷰모드 래퍼(`bg-white/5`), `ColorPicker` 드롭다운(`bg-gray-900`)·`BlogEditor`의 `tone==='dark'` 분기는 현재 어떤 호출처도 사용하지 않는 다크 전용 잔재다. 텍스트 대비 결함은 아니나(데코/미사용 분기), 라이트 통일 마감 시 별도 패스로 정리 권고. 본 라운드 T08 범위(회색 텍스트 -400) 밖이라 미수정.
- **코드블록 복사 버튼**: prose 코드블록을 라이트로 전환하는 결정이 추후 내려지면 `BlogPostContent.tsx:40` 의 `bg-white/10 text-gray-400` 도 함께 라이트화 필요(현재는 다크 코드블록 전제로 보존이 정답).
- **CommentSection 추천 버튼**: ThumbsUp 아이콘 + 좋아요 수(숫자) 형태로 가시 텍스트(숫자)는 있으나 "추천" 의미가 스크린리더에 전달되지 않는다. 4-1의 "아이콘 전용(텍스트 부재)" 기준 밖이라 미변경. 추가 하드닝 시 `aria-label="추천"` 부여 고려.
