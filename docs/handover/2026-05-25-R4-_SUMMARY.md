## 핵심 산출

- **게시글 비추 실집계**: `togglePostLike`가 `dislikeCount` 반환, `PostVoteButtons`의 가짜 `비추 {disliked?1:0}` → 실값 `비추 {dislikes}`.
- **댓글 추천 결선**: `toggleCommentLike`(PATCH) 신규 + `CommentSection` ThumbsUp onClick 연결(댓글별 busy 가드).
- **실 DB 적용 길**: 마이그레이션 2종 검증 완료 + 운영자용 push 런북 + 스모크 스크립트 → 운영자가 1회 실행으로 적용·검증.
- **news-queries 정리**: SSR 전환으로 unused가 된 클라 fetch 5종 + 전용 타입/상수 제거, 순수 헬퍼·매퍼·타입은 server 모듈이 쓰므로 보존.
