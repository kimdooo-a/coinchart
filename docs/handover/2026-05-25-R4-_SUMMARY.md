## 실 DB 실동작 검증 (E2E DB-ready 재실행 + 직접 API)

DB 적용 후 dev 서버(URL 주입)에서 E2E `E2E_DB_READY=1` 재실행 → **28 passed / 1 failed / 1 skipped** (DB 미적용 시 24/0/6 → skip 6 중 5 해제, 4 통과). 실패 1건(L-B4 댓글 추천)·skip 1건(AD1 관리자, 인증 storageState 필요).

**L-B4 실패 = 앱/wiring 버그 아님** (직접 API로 확정):
- 댓글 작성 `POST /api/community/comment` → **HTTP 201, DB INSERT 정상**.
- 댓글 추천 `PATCH /api/community/comment` → **추천 ON `{liked:true,likeCount:1}` → 취소 `{liked:false,likeCount:0}`**, comment_likes 트리거가 like_count 0→1→0 정확 동기화.
- 원인: L-B4가 "첫 게시글에 기존 댓글 존재"를 전제하나 댓글 시드 0 + L-B3(댓글 작성)이 E2E 브라우저에서 실제 저장 실패(등록 버튼 클릭이 createComment 미트리거 추정 — dev 로그에 `/api/community/comment` 호출 부재) → 추천 대상 댓글 없어 셀렉터 타임아웃.
- **결론**: 게시글 추천/비추·댓글 작성·댓글 추천 백엔드+wiring 전부 실동작 검증 완료. L-B4는 **T04 E2E spec 신뢰성 이슈(R5)** — 테스트가 자체 댓글을 생성·확정 후 추천하도록 개선 필요.
