## 2. 구현 상세

### 2-1. Provider 루트 승격 (`app/layout.tsx`)
- `import { DisplaySettingsProvider } from "@/lib/config/display-settings"` 추가.
- 마운트 위치: `<LanguageProvider>` 바로 안쪽. `<GlobalHeader />`와 본문 `<div>{children}</div>`을 모두 `<DisplaySettingsProvider>`로 감쌈.
  - 헤더(글로벌 시세 스트립 등 향후 구독자 포함)도 Provider 범위에 들어오도록 안쪽에 배치.
- 단일 마운트 — 전역 SSOT.

### 2-2. WatchlistTable 구독 (`components/Watchlist/WatchlistTable.tsx`)
- `const { formatPrice, changeColorClass } = useDisplaySettings();` 추가.
- **가격**: `formatPrice(quote?.price ?? null)`(로컬 format.ts) → `quote?.price != null ? formatPrice(quote.price) : '—'`.
  - Context `formatPrice`는 `(usdValue: number) => string`로 **null을 받지 않으므로** null 가드를 호출부에서 처리(로컬 헬퍼의 `null→'—'` 동작 보존).
  - 동작: USD 기준값을 표시 통화로 환산. USD 모드=`$...`, KRW 모드=`₩...`(환율 `/api/kimchi`, 폴백 1450).
- **등락 색**: `trendColor`를 `pct == null ? 'text-on-surface-variant' : changeColorClass(pct)`로 대체.
  - KR=빨↑(`text-kr-up`)/파↓(`text-kr-down`), GLOBAL=녹↑(`text-new`)/빨↓(`text-positive`). flat/값없음=중립.
- 로컬 `format.ts`의 `formatPrice` import 제거. `formatPct`·`formatVolume`·`baseSymbol`·`symbolSlug`는 유지.
- `isUp`은 화살표(▲/▼) 표기에 계속 사용하므로 유지.

### 2-3. 색상 클래스 정합 확인
- `lib/config/display-settings.tsx`의 `getChangeColorClass`가 반환하는 `text-kr-up`/`text-kr-down`/`text-new`/`text-positive`는 모두 `app/globals.css`의 **`@theme` 블록**에 `--color-*`로 정의되어 있어 Tailwind v4가 유틸리티를 자동 생성 → 전부 유효 클래스(확인 완료). 기존 임의값(`text-[var(--color-kr-up)]`)과 색상 동일(`--color-kr-up`=`#ba1a1a`, `--color-kr-down`=`#0050cb`).

## 3. 구독 적용 컴포넌트 목록

| 컴포넌트 | 구독 여부 | 비고 |
|----------|----------|------|
| `WatchlistTable` | ✅ 적용 | 가격(`formatPrice`)·등락 색(`changeColorClass`) |
| `WatchlistView` | ⛔ 미적용(불필요) | 가격·색을 **직접 렌더하지 않음**. 표는 `WatchlistTable`에 위임, 등락률 정렬은 `changePct` 숫자만 사용(색 무관), `EmptyState`/타이틀 ⭐는 브랜드 그린(`--color-new`, 등락 무관). 추가 구독 불요 |

> 지시서의 "WatchlistTable(+WatchlistView)" 중 **실제 표시 전환이 필요한 곳은 WatchlistTable 뿐**임을 확인. WatchlistView는 의도적으로 미접촉(불필요한 변경 방지).
