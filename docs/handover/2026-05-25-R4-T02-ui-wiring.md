## 수정 파일 (3개, 모두 T02 전용 쓰기 영역)

### 1. `lib/community/board-queries.ts`
- **`togglePostLike` 반환 확장**: `Promise<{ liked, likeCount }>` → `{ liked, likeCount, dislikeCount }`.
  - 응답 파싱 타입에 `dislikeCount?: number` 추가, `Number(json.dislikeCount ?? 0)`로 파싱해 함께 반환.
  - 기존 호출부 호환 — 필드 추가만(기존 구조분해 `{ liked, likeCount }`는 그대로 동작).
- **`toggleCommentLike` 신규 추가**: `PATCH /api/community/comment` 래퍼.
  ```ts
  export async function toggleCommentLike(
    commentId: string, value: 1 | -1 = 1
  ): Promise<{ liked: boolean; likeCount: number }>
  ```
  - body `{ commentId, value }`, `togglePostLike`와 동일한 graceful 에러 패턴(`!res.ok → throw new Error(json.error ?? ...)`).
  - 익명 dedup 헤더(`x-client-ip-hash`)는 middleware 자동 주입 — 클라 명시 안 함(주석 명기).

### 2. `components/community/PostVoteButtons.tsx`
- `initialDislikes?: number` prop 추가(**optional, default 0**), `dislikes` 상태 신규(`useState(initialDislikes)`).
- `handleLike`/`handleDislike`에서 `togglePostLike` 반환의 `dislikeCount`를 `setDislikes(dislikeCount)`로 반영.
- 표시부 `비추 {disliked ? 1 : 0}` → **`비추 {dislikes}`** (실제 분리 집계 수).
- 추천/비추 상호 배타 토글 로직(`liked`/`disliked`)은 유지, 카운트만 응답 기반으로 전환.

### 3. `components/community/CommentSection.tsx`
- `toggleCommentLike` import 추가.
- `likeBusyIds: Set<string>` 상태 신규 — 진행 중 댓글 id 중복 클릭 가드(`PostVoteButtons`의 `likeBusy` 패턴 차용, 댓글별 독립 가드).
- `handleCommentLike(commentId)` 핸들러: `toggleCommentLike(id, 1)` 호출 → 응답 `likeCount`로 `comments` 상태 배열의 해당 id `likes` 확정 갱신.
- 댓글·대댓글 ThumbsUp 버튼 2곳에 `onClick={() => handleCommentLike(c.id/cc.id)}` + `disabled={likeBusyIds.has(id)}` 연결.
- 추천순 정렬은 `sortedTopComments`가 `comments` 상태에서 파생되므로 `setComments` 갱신 시 재정렬 자동 반영(확인 완료).
