### 후속(선행 의존, R12 내 2차 또는 R13)
- **W2**: 현장 ⭐ 토글 공용 컴포넌트 → 코인룸·analysis·stock·시세스트립 4곳 (의존 T-A)
- **S2**: 표시설정 전역 적용 — 시세 표시 컴포넌트들이 Context 구독 (의존 T-B)
- **D3**: 회원 동기화 머지 — 로그인 시 로컬우선 업로드, 회원이면 DB 소스 전환 (의존 T-A+T-C)

### Wave/병렬
- **Wave 1**: T-A · T-B · T-C **완전 독립 = 동시 발사**.
- **Wave 2**: T-D(라우트 존재 후) · W2 · S2 · D3(각 선행 합류 후).
- **MVP 경계**: T-A + T-B + T-D + S2 = **익명 기준 완전 동작(서버 0)**. T-C·D3는 회원 동기화 부가가치(분리 출시 가능).

### SSOT·충돌 가드
- crypto→`lib/supabase/crypto.ts`, stock→`lib/supabase/stock.ts` 교차 임포트 0 (ESLint no-restricted-imports).
- watchlist DB 접근은 신규 `lib/supabase/watchlist.ts` SSOT로 (T-C 소유).
- 쓰기 영역 겹침 0 확인: T-A(watchlist·hooks) / T-B(settings·config) / T-C(api·supabase) / T-D(common) — 분리됨.
