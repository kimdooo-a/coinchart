## 3. Phase 2 — 본 영역 참조 정리

### 3-1. `scripts/seed-community.ts` (시드 데이터 fixture 이관)

시드 스크립트는 `MOCK_POSTS`(free/market/info 각 52행, 총 156행)를 실제로 필요로 한다 →
지시서 옵션대로 **시드 전용 데이터부를 `scripts/fixtures/community-posts.ts`로 신규 이관**했다 (근거: app/lib은 실데이터 전환 완료, 더미는 dev seed에서만 필요).

- **신규**: `scripts/fixtures/community-posts.ts`
  - 이관 항목: `MockPost` 인터페이스, `generatePosts`/`pick`/`relativeTime` 헬퍼, 더미 제목·닉네임·IP·코인심볼 배열, `MOCK_POSTS`
  - **드롭(전역 unused 확인)**: `getPost`/`getPostsByBoard`/`getTotalPages`/`getBestPosts`/`getPostsForCoin`/`MockComment`/`MOCK_COMMENTS` — 어떤 페이지도 import하지 않음(R1~R2에서 실데이터 전환됨). seed가 안 쓰므로 함께 제거.
  - 슬러그 메타는 SSOT 그대로 참조: `import { BOARD_META, type BoardSlug } from "../../lib/community/board-meta"` (+ `BoardSlug` 재노출로 seed가 단일 경로 import 가능)
- **수정**: `scripts/seed-community.ts`
  - L21 import 경로만 `../lib/community/mock-posts` → `./fixtures/community-posts` (심볼명 `MOCK_POSTS`/`MockPost`/`BoardSlug` 동일 유지 → 본문 churn 0)
  - L5 헤더 주석의 출처 경로 갱신

import는 R2에서 이미 위젯별 `board-queries` fetch로 전환되어 mock 의존 0. 주석에만 삭제될 파일명("mock-coins")이 남아 정리:
