## 1. 작업 요약

R2까지 board/news/coin이 실데이터로 전환됐으나, `mock-posts.ts`/`mock-news.ts`에 정적 메타(게시판/뉴스 카테고리·필터 정의)가 남아 페이지들이 mock 파일을 계속 import 중이었다.
R3 목표인 mock 완전 삭제(T05)의 **선행 작업**으로, 정적 메타를 mock과 무관한 독립 SSOT 파일로 분리하고 기존 mock 경로는 re-export로 하위호환을 유지했다.

**데이터 배열(MOCK_POSTS / MOCK_NEWS / MOCK_COMMENTS)과 생성 로직은 손대지 않음** (T05 영역).

## 4. re-export 방식 (하위호환 유지)

기존 import 경로를 무파손 유지하기 위해, 원본 mock 파일에서 정의를 제거하고 import + 재노출로 교체:

**`mock-posts.ts`** (상단):
```ts
import { BOARD_META, type BoardSlug } from "./board-meta";
export { BOARD_META };
export type { BoardSlug };
```
- 내부 로직(`generatePosts`, `MOCK_POSTS`, `getPostsByBoard` 등)이 `BOARD_META`·`BoardSlug`를 계속 사용하므로 import 후 재노출.

**`mock-news.ts`** (상단):
```ts
import { NEWS_CATEGORIES, COIN_FILTERS } from "./news-meta";
export { NEWS_CATEGORIES, COIN_FILTERS };
```
- 내부 `filterNews`가 `NEWS_CATEGORIES`를 사용하므로 import 후 재노출. `COIN_FILTERS`는 내부 미사용이나 재노출 대상이라 import 유지.

→ 이로써 Wave 2(T02~T04)가 새 경로로 전환하기 전이라도 기존 `mock-*` import가 그대로 동작 (graceful).

## 5. 새 import 경로 안내 (T02~T04용)

T02·T03·T04는 아래 **신규 경로**로 전환할 것 (mock-* 경로 대신):

```ts
// 게시판 (T02 board, T04 coin)
import { BOARD_META, type BoardSlug } from "@/lib/community/board-meta";

// 뉴스 (T03 news, T04 coin)
import { NEWS_CATEGORIES, COIN_FILTERS } from "@/lib/community/news-meta";
```

전환 대상 (현재 mock 경로 사용 중인 코드 파일):
- `app/board/[slug]/page.tsx` — `BOARD_META`, `BoardSlug` (from mock-posts)
- `app/board/[slug]/[postId]/page.tsx` — `BOARD_META`, `BoardSlug` (from mock-posts)
- `app/board/[slug]/write/page.tsx` — `BOARD_META`, `BoardSlug` (from mock-posts)
- `app/news/page.tsx` — `NEWS_CATEGORIES`, `COIN_FILTERS` (from mock-news)
- `scripts/seed-community.ts` — `BoardSlug`(type), `MockPost`(type), `MOCK_POSTS`(data) (from mock-posts)
  - ⚠️ `MockPost`/`MOCK_POSTS`는 mock 잔류 심볼이므로 T05 삭제 시점에 별도 처리 필요. `BoardSlug`만 board-meta로 이동 가능.

→ T05는 모든 사용처가 신규 경로로 전환된 뒤 mock-* 파일의 데이터·re-export를 최종 삭제.
