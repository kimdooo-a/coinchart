# R4/T03 — dead code 정리 (news-queries.ts SSR 전환 후 unused 제거)

- 날짜: 2026-05-25
- 라운드: R4 (community-wiring) · Wave 1 (독립)
- 대상 파일(단일): `lib/community/news-queries.ts`
- 격리 준수: `news-queries.ts` 1파일만 수정. 그 외 파일 무수정.

## 1. 배경

`lib/community/news-queries.ts`는 R2/T02에서 `/news`(당시 `"use client"`) 전용 클라 fetch 래퍼로
만들어졌다. R3/T03에서 `/news`가 **SSR(`lib/community/news-server.ts`, server-only) 로 전환**되며
클라 fetch 함수들의 호출처가 모두 사라졌다. 순수 헬퍼/타입/매퍼는 server 모듈이 여전히 재사용하므로
파일 자체는 보존하고, unused fetch 래퍼와 그 전용 내부 상수/타입만 제거했다.

## 5. 잔존 의심 dead code (R5 후보 메모, 본 작업 범위 외)

- `components/news-rotator.tsx`: 내부 `fetchNews` 로컬 함수 보유. 별개 컴포넌트라 본 작업 무관 —
  실제 마운트/사용 여부는 미확인. R5에서 컴포넌트 단위 dead code 점검 시 후보.
- `lib/community/coin-queries.ts`: news-queries와 유사하게 R2 클라 fetch 래퍼(`fetchTickers`/
  `fetchCoinPosts`/`fetchCoinNews`/`fetchHotIssues`/`fetchFng`/`fetchOfficialPosts` 등)를 보유.
  R3에서 `/coin/[symbol]`이 SSR(`coin-server.ts`)로 전환됐다면 동일하게 unused 클라 fetch가
  남아있을 가능성. **본 T03 격리 범위(news-queries.ts) 밖**이므로 미수정 — R5 dead code 정리 후보로 강력 추천.
