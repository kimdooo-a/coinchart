## 4. 🔴 사용자 조치 필수 (T03 에스컬레이션)

**daily-cron이 2026-05-25부터 전면 실패 중. 원인은 코드가 아니라 GitHub 계정 결제 차단.**

- run annotation: *"The job was not started because recent account payments have failed or your spending limit needs to be increased."*
- job이 3~4초에 시작도 못 하고 종료(setup-node 도달 전) → 계정 레벨 차단.
- ⚠️ **레포 Public 전환만으로는 부족**: 계정에 결제 hold가 걸리면 Public 레포 Actions까지 차단됨. R13의 "Public 전환=무료화" 전제는 **불완전**했다.
- **조치**: GitHub → Settings → **Billing & plans**(`kimdooo-a`) 에서 결제 수단 갱신 또는 spending limit 상향 → `gh workflow run daily-cron.yml`로 수동 트리거 후 success 확인.
- 5-24 이후 데이터 동기화 정지 가능성 → 결제 정상화 후 `coinchart.vercel.app` 갱신 확인.
