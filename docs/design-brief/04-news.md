# 디자인 의뢰서 — 04. 뉴스 강화 페이지

> **URL**: `/news`
> **목적**: 크롤링된 뉴스를 코인·카테고리·호악재·중요도 4차원으로 분류해 보여주고, 사용자가 뉴스를 클릭해 토론으로 이어가게 한다.
> **참고**: 네이버 뉴스 (좌측 카테고리 + 메인 뉴스 + 우측 사이드바), 코인데스크 헤드라인, 코인판 시세·뉴스 영역
> **현재 상태**: `app/news/page.tsx` 존재, 카드형 무한스크롤. **리디자인 대상**.

---

## 1. 페이지의 한 줄 정의

> "좌측 코인·카테고리 필터 → 메인 영역 뉴스 표(호악재·중요도 시각화) → 우측 사이드바(랭킹·시세·핫이슈)."

## 3. 섹션별 명세

### 3-1. 페이지 헤더

- 좌측: 페이지 타이틀 + 한 줄 설명
- 우측: 언어 토글 (한/영)
- 보더 하단

### 3-2. 필터 바

- 가로 4줄 또는 압축된 1줄(가로 스크롤)
- 4개 차원: **코인 / 분류 / 감정 / 정렬**
- 각 줄: 좌측 라벨("코인:") + 칩 버튼 가로 나열
- 칩 버튼:
  - 비활성: `--bg-secondary` 배경, `--text-secondary` 텍스트, 보더 1px
  - 활성: 브랜드 컬러 배경, 흰 텍스트
  - 감정 칩은 시맨틱 색 적용 (호재=빨강 배경, 악재=파랑 배경 등)
- URL 쿼리스트링 동기화 (`?coin=btc&cat=etf&sentiment=positive&sort=latest`)
- 모바일: 첫 줄(코인)만 노출, "필터 더보기" 버튼으로 나머지 펼침

### 3-3. 오늘의 헤드라인 (Top 3)

- 가로 3분할 카드
- 카드 1개 구조:
  ```
  ┌─────────────────────┐
  │ [🔴 호재 / 중요도★8]   │
  │ 카테고리: ETF          │
  │                       │
  │ 헤드라인 제목 (2줄)    │
  │                       │
  │ 요약 (1~2줄, 회색)     │
  │                       │
  │ 매체  ·  10분 전        │
  │ 💬 24 [토론 →]         │
  └─────────────────────┘
  ```
- 헤드라인 선정 기준: 중요도 점수 + 호재 / 악재 / 중립 각 1개씩 균형
- 카드 보더 1px, 패딩 16px
- 호버 시 보더 색 변화

### 3-4. 뉴스 표 (NewsTable)

- 50개 행, 페이지네이션 또는 무한스크롤(둘 중 결정)
- 행 구조:
  ```
  | 시간 | 태그(코인+카테고리) | 🔴/🔵 제목 | 매체 | 중요도 ★점수 | 💬N |
  ```
- **시간**: `10분전`, `2시간전`, `1일전` 형식. 우측 정렬, `--text-tertiary`
- **태그**: 작은 사각 뱃지 2개 (코인 + 카테고리), 가로 나열
  - 코인 뱃지: 코인 컬러 (BTC=오렌지, ETH=보라, XRP=파랑 등)
  - 카테고리: 회색 배경
- **제목 영역**: 좌측에 감정 점(🔴 8x8 원), 그 다음 제목, 가장 두드러지게
  - 클릭 시: **새 탭으로 원문 이동**
  - 우측에 `[💬 N 토론]` 버튼 (작게) → 클릭 시 사이트 내 토론 페이지로 (`/board/info/news-{id}` 또는 정보공유에 자동 게시된 글로)
- **매체**: 출처 매체명, `--text-secondary`, 작은 별 점수 (★★★★★)
- **중요도**: ★ 1~10 시각화 (작은 막대 또는 숫자)
- 행 호버: 배경 변화

### 3-5. 우측 사이드바

순서:
1. **실시간 시세 위젯**
2. **핫이슈** (실시간 검색어)
3. **공포·탐욕 지수**
4. **코인별 뉴스 랭킹** (오늘 뉴스 많은 순 TOP 5)
5. **매체 신뢰도** (TOP 10, 별점)
6. **공식글** (블로그 링크 3개)

## 4. 인터랙션·상태

| 요소 | 상태 | 처리 |
|------|------|------|
| 필터 칩 | 클릭 | URL 변경, 표 부분 리로드, 활성 칩 색 변화 |
| 헤드라인 카드 | 클릭 | 새 탭 원문 이동 |
| 헤드라인 [토론 →] | 클릭 | 사이트 내 정보공유 게시판의 자동 생성 글로 이동 |
| 뉴스 행 | 호버 | 배경 변화 |
| 뉴스 제목 | 클릭 | 새 탭 원문 |
| [💬 토론] | 클릭 | 사이트 내 토론으로 |
| 정렬 변경 | - | 표 리로드 |
| 더 보기 | - | 다음 50개 추가 |

## 7. Stitch 의뢰 시 추가 지시

```
페이지 명: 뉴스 (강화판)
타입: 데스크톱 + 모바일
스타일: 네이버 뉴스 좌측 영역 + 코인데스크 헤드라인
요점: 4차원 분류(코인·카테고리·감정·중요도)가 한눈에 보여야 함
시각화:
  - 감정: 🔴 빨강 점(호재), 🔵 파랑 점(악재), ⚪ 회색(중립), 🟣 보라(혼조)
  - 중요도: ★ 또는 막대 (1~10)
  - 코인 태그: 코인별 색상 (BTC=오렌지, ETH=보라, XRP=파랑, SOL=청록 등)
한국식: 빨강↑(호재) 파랑↓(악재)
회피: 큰 카드 50개 무한스크롤 (현재 디자인), 컬러 과다 사용
강조: 표 형식, 정보 밀도, 필터의 직관성
```

## 8. 룰베이스 분류 시각화 가이드 (백엔드 ↔ 디자인 매핑)

> 이 표는 **백엔드 작업 시 참고용**이지만, 의뢰서에 함께 보내면 디자이너가 시각화를 더 정확히 할 수 있습니다.
