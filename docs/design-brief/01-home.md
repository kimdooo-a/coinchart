# 디자인 의뢰서 — 01. 메인(홈) 페이지

> **URL**: `/`
> **목적**: 사이트 첫인상에서 "여기는 코인·주식 정보 공유 커뮤니티구나"를 0.5초 안에 인지시킨다. 베스트글·최신글·실시간 시세·뉴스 헤드라인을 한 화면에 밀도 있게 배치.
> **참고할 것**: 코인판(coinpan.com) 메인, 네이버 메인 화면 좌측 영역, dcinside 갤러리 메인

---

## 1. 페이지의 한 줄 정의

> "들어오자마자 **인기글 30개**가 보이고, 우측에는 **시세·핫이슈·뉴스 위젯**, 하단에는 **각 게시판 미리보기 5줄씩**이 있는 정보 허브 메인."

## 3. 섹션별 상세 명세

### 3-1. 시세 스트립 (Top Marquee) — 메인 최상단

- 가로로 8~12개 코인 + 주요 주식(SPY, QQQ, AAPL 등) 시세를 한 줄로 흘러가게
- 항목 1개: `[심볼] [가격] [등락률 ▲ 또는 ▼ 컬러]`
- 자동 스크롤 (가로) 또는 수동 화살표
- 클릭 시 해당 코인룸/주식 분석 페이지로 이동
- 한국식 색: 상승=빨강(`--positive`), 하락=파랑(`--negative`)
- 높이: 약 36px, 배경 `--bg-secondary`

### 3-2. 🔥 베스트 (오늘) 섹션 — 최우선 정보

- 섹션 헤더: 좌측 "🔥 베스트" + 작은 부제 "오늘 인기글 30개", 우측 "더보기" 링크 + 시간/주간 토글
  - 토글: `오늘 / 이번주 / 이번달` (탭)
- 본문: 게시글 행 30개 (페이지네이션 없이 한 번에)
- 행 구조 (BoardRow 컴포넌트, 00-overview §9-1 참조):
  ```
  [순위 1.] [HOT] [공지] 글 제목 [💬32] [📷]   |  작성자 닉(IP)  2시간전  조회 1.2k  ❤45
  ```
- 순위 1~3은 글자 크기 약간 키움 또는 강조 컬러 (선택)
- 익명 작성자: 닉네임 다음에 `(211.34.*.*)` 작은 회색 글자
- 회원: 닉네임만 (마이크로 뱃지 가능)

### 3-3. 📰 최신 뉴스 섹션

- 섹션 헤더: "📰 최신 뉴스" + "더보기"(→/news)
- 행 10개, 행 구조:
  ```
  [호재/악재 컬러 점] [카테고리] 뉴스 제목      |  매체명  10분전
  ```
- 호재/악재 점: 8x8 원, 한국식 색 (호재=빨강, 악재=파랑, 중립=회색, 혼조=보라)
- 카테고리 태그: 작은 회색 사각 (`시장동향`, `규제`, `기술`, `거래소`, `ETF`, `온체인`, `매크로`)
- 매체명: `--text-tertiary` 작은 글자
- 클릭 시 새 탭으로 원문 이동 + 사이트 내 "이 뉴스에 대한 글" 토론 진입 옵션 (작은 💬 아이콘)

### 3-4. 게시판별 미리보기 (3컬럼)

- 가로 3컬럼: 자유게시판 / 시세토론 / 정보공유
- 각 컬럼 헤더: 게시판 이름 + "더보기"
- 각 컬럼 본문: 글 제목 5줄 (제목+시간+댓글수만, 압축 표기)
- 제목이 길면 ellipsis (`...`)
- 모바일에서는 1컬럼 세로 스택 또는 가로 스와이프

### 3-5. 코인룸 진입 카드

- 가로 6개 카드 (모바일 가로 스크롤)
- 카드 1개: `[BTC]` 큰 글자 + 현재가 + 24h 등락률 + 작은 라인차트
- 클릭 시 `/coin/btc` 진입
- 6종: BTC / ETH / XRP / SOL / 알트(통합) / 김프(김치프리미엄)

## 4. 사이드바 위젯 (우측 300px)

순서대로 위에서 아래로:

### 4-1. 실시간 시세 위젯

- 헤더: "실시간 시세" + 새로고침 아이콘
- 8개 코인+주요 주식, 1줄 = 1종목
- 1줄: `[로고] 심볼 (이름) | 현재가 | 등락 ▲/▼`
- 한국식 색

### 4-2. 핫이슈 (실시간 검색어)

- 헤더: "🔍 핫이슈"
- 1~10위 리스트, 1줄 = 1키워드
- 옆에 변동 표시 (▲ NEW, ↑ 2단계 상승, − 유지)
- 클릭 시 검색 결과로

### 4-3. 공포·탐욕 지수 (FNG)

- 헤더: "공포·탐욕 지수"
- 게이지 차트 (반원, 0~100)
- 현재 값 + 라벨 ("Greed", "탐욕")
- 어제/지난주 비교 (작게)

### 4-4. 공식글 (블로그) 최신

- 헤더: "공식글" + "더보기"(→/blog)
- 3~5개 블로그 포스트
- 1줄: 제목만 + 날짜 작게

### 4-5. 도구 단축

- 헤더: "🛠 도구 바로가기"
- 2x2 그리드 작은 카드: 차트분석 / AI시그널 / 마켓무드 / 캘린더
- 카드: 아이콘 + 라벨, 클릭 시 해당 도구 페이지로

### 4-6. (선택) 광고 영역

- v2.1 이후 추가. 1차 디자인에서는 자리만 표기 또는 제외.

## 6. 인터랙션·상태

| 요소 | 상태 | 처리 |
|------|------|------|
| 베스트 글 행 | 호버 | 배경 `--bg-secondary` |
| 베스트 글 행 | 방문 | 제목 색 `--text-secondary` (회색) |
| 베스트 글 행 | HOT 뱃지 | 댓글 50+ 또는 추천 10+ 일 때 자동 표시 |
| 시세 스트립 | 가격 변동 | 1초 깜빡임 (빨강↑/파랑↓) |
| 사이드바 시세 | 로딩 | 스켈레톤 |
| FNG 게이지 | 항상 | 24h 캐시, 새로고침 시 부드러운 애니메이션 |
| 글쓰기 버튼 | 클릭 | 게시판 선택 모달 → 작성 페이지 |

## 9. Stitch 의뢰 시 추가 지시

