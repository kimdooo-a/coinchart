# 디자인 의뢰서 — 00. 디자인 시스템 개요 (공통)

> **이 문서는 모든 페이지 의뢰서(01~05)의 공통 베이스입니다. Stitch에 페이지를 의뢰할 때 이 문서의 "톤·컬러·타이포·간격·컴포넌트" 섹션을 함께 첨부하세요.**

---

## 1. 프로젝트 한 줄 정의

> **한국 투자자를 위한 코인·주식 정보 공유 커뮤니티.** 자유 토론 게시판, 큐레이션된 뉴스, 코인별 토론룸이 한 자리에 있는 사이트.

- 영감: 코인판(자유게시판 중심) + 네이버(정보 밀도·표 형식·사이드바 위젯)
- 사이트명: **ChartMaster Community** (또는 한글 브랜드명 추후 결정)
- 타겟: 한국어 사용자, 코인·주식 투자에 관심 있는 20~50대

---

## 2. 디자인 톤 (반드시 지킬 4가지)

1. **밝은 배경** — 흰색(#FFFFFF) 메인 콘텐츠, 라이트 그레이(#F5F6F8) 사이드바·구분 영역. 다크모드는 1차 범위 외.
2. **타이트한 정보 밀도** — 한 화면에 많은 글 제목이 보이도록. 과도한 카드 그림자·여백 지양.
3. **리스트·표 우선** — 게시판은 카드형이 아닌 **표 형식 1줄 = 1글**. 글 제목·작성자·시간·조회·추천이 한 줄에 들어감.
4. **사이드바 위젯 강조** — 우측 사이드바는 정보 허브. 인기글 / 실시간 시세 / 핫이슈 / 광고(추후).

❌ **피할 것**:
- 풀스크린 히어로 이미지 (화려함은 코인판 정체성과 안 맞음)
- 큰 카드형 게시글 (정보 밀도 떨어짐)
- 둥근 모서리 과다 사용 (rounded-2xl 같은 큰 라운드 ❌, rounded-md 정도)
- 그라디언트·네온 효과 (현재 사이트의 다크 프리미엄 톤은 의도적으로 폐기)

## 3. 컬러 팔레트

### 3-1. 베이스

| 토큰 | HEX | 용도 |
|------|-----|------|
| `--bg-primary` | `#FFFFFF` | 메인 배경 |
| `--bg-secondary` | `#F5F6F8` | 사이드바·구분 영역·헤더 배경 |
| `--bg-tertiary` | `#FAFAFA` | 호버·짝수 줄 배경(zebra) |
| `--border` | `#E5E7EB` | 일반 보더 |
| `--border-strong` | `#D1D5DB` | 강조 보더·구분선 |

### 3-2. 텍스트

| 토큰 | HEX | 용도 |
|------|-----|------|
| `--text-primary` | `#111827` | 본문·제목 |
| `--text-secondary` | `#4B5563` | 보조 정보 (작성자·시간) |
| `--text-tertiary` | `#9CA3AF` | 메타 정보·플레이스홀더 |
| `--text-link` | `#1D4ED8` | 링크 (방문 후 `#7C3AED`) |

### 3-3. 포인트 (브랜드)

| 토큰 | HEX | 용도 |
|------|-----|------|
| `--brand-primary` | `#03C75A` | 메인 브랜드 (네이버 그린 차용 가능, 또는 `#0066FF` 블루) |
| `--brand-primary-hover` | `#02A14A` | 호버 |

> **결정 필요**: 그린(네이버 톤) vs 블루(일반 핀테크 톤). 의뢰 시 양쪽 시안 받아 비교.

### 3-4. 시맨틱 (호재/악재)

| 토큰 | HEX | 용도 |
|------|-----|------|
| `--positive` | `#E12C2C` | **호재·상승·매수** (한국 증시 관습: 빨강=상승) |
| `--negative` | `#1A6FCC` | **악재·하락·매도** (한국 증시 관습: 파랑=하락) |
| `--mixed` | `#9333EA` | 혼조 |
| `--neutral` | `#6B7280` | 중립 |

> ⚠️ **중요**: 글로벌(미국)식 색상(녹=상승, 빨=하락)이 아닌 **한국식**(빨=상승, 파=하락) 사용. 사용자 답변 "네이버 스타일·코인판 사용자"가 한국인 투자자 기준.

### 3-5. 강조·뱃지

| 토큰 | HEX | 용도 |
|------|-----|------|
| `--hot` | `#FF6B35` | 인기글·HOT 뱃지 |
| `--new` | `#10B981` | 신규 뱃지 (예외적 그린) |
| `--notice` | `#FBBF24` | 공지 뱃지 |

## 4. 타이포그래피

### 4-1. 폰트 패밀리

```css
--font-sans: 'Pretendard', 'Noto Sans KR', -apple-system, system-ui, sans-serif;
--font-mono: 'D2 Coding', 'Consolas', monospace;
```

- 한글: **Pretendard Variable** 우선, 폴백으로 Noto Sans KR
- 영문·숫자: 동일 (Pretendard가 영문 폼도 지원)
- 코드·시세 숫자: D2 Coding 또는 시스템 모노

### 4-2. 스케일

| 클래스 | 크기 | 굵기 | 줄높이 | 용도 |
|--------|------|------|--------|------|
| `text-xs` | 12px | 400 | 1.4 | 메타·캡션 |
| `text-sm` | 13px | 400 | 1.5 | 본문 작은 (게시판 부가정보) |
| `text-base` | 14px | 400 | 1.6 | 게시판 글 제목 (기본) |
| `text-md` | 15px | 500 | 1.6 | 본문 |
| `text-lg` | 16px | 500 | 1.5 | 섹션 제목 |
| `text-xl` | 18px | 700 | 1.4 | 게시판 헤더·페이지 제목 |
| `text-2xl` | 22px | 700 | 1.3 | 게시글 본문 제목 |
| `text-3xl` | 28px | 800 | 1.2 | 홈 메인 헤드라인 (예외) |

> 네이버 톤은 본문 14px가 기본. 13~14px 글 제목으로도 충분히 읽힘. 18~24px 큰 제목은 게시글 상세 정도에만.

## 5. 간격 시스템

```
4px / 8px / 12px / 16px / 20px / 24px / 32px / 40px / 48px / 64px
```

- 카드 내부 패딩: 16px (`p-4`)
- 섹션 사이 간격: 24~32px
- 게시판 행 패딩: 세로 8~10px (타이트하게)
- 컨테이너 좌우 패딩: 16px (모바일) / 20px (태블릿) / 24px (데스크톱)

## 6. 레이아웃 그리드

### 6-1. 데스크톱 (1280px+)

```
[ Header (60px 고정) ]
[─────────────────────────────────────────────]
[ Main Content (760px) | Sidebar (300px) ]   ← Gap 24px
[─────────────────────────────────────────────]
[ Footer ]
```

- 최대 너비: **1200px** 컨테이너 (좌우 자동 마진)
- 메인 + 사이드바 비율: 약 72% : 28%

### 6-2. 태블릿 (768~1279px)

- 사이드바 → 메인 하단으로 내려옴 (Stack)
- 또는 사이드바 일부 위젯만 메인 영역에 인라인 노출

### 6-3. 모바일 (~767px)

- 1단 레이아웃
- 사이드바는 메인 하단으로
- 헤더는 햄버거 메뉴
- 게시판은 표 형식 → 모바일에서는 약간 축약 (조회/추천 숫자만 한 줄로)

## 7. 헤더 (전 페이지 공통)

```
┌────────────────────────────────────────────────────────────────────────┐
│ [로고]  베스트  자유게시판  시세토론  정보공유  뉴스  ┊ 코인룸▼ 도구▼  ┊ [🔍] [로그인][글쓰기] │
└────────────────────────────────────────────────────────────────────────┘
```

- 높이: 60px
- 배경: 흰색 + 하단 1px `--border` 보더 (스크롤해도 고정)
- 로고: 좌측, 텍스트형 또는 작은 아이콘+텍스트
- 메뉴: 7~8개 1차 메뉴 + 2개 드롭다운
  - 1차: 베스트 / 자유게시판 / 시세토론 / 정보공유 / 뉴스
  - 드롭다운: 코인룸▼(BTC/ETH/XRP/SOL/알트/김프), 도구▼(차트분석 코인/주식/AI시그널/마켓무드/캘린더/워치리스트/보안메모)
- 우측: 검색 아이콘, 로그인 버튼(미로그인) 또는 닉네임+드롭다운(로그인), **글쓰기 버튼**(브랜드 컬러 강조)
- 모바일: 햄버거 메뉴 + 로고만, 글쓰기 버튼은 플로팅 FAB

---

## 8. 푸터 (전 페이지 공통)

- 흰 배경 + 상단 보더
- 좌측: 로고, 사이트 한 줄 소개, 운영자 정보
- 가운데: 빠른 링크 (이용약관 / 개인정보처리방침 / 문의 / 공식글(블로그))
- 우측: 면책 고지 ("본 사이트의 모든 정보는 투자 권유가 아닙니다")
- 색: `--bg-secondary` 배경, `--text-secondary` 텍스트
- 패딩: 위아래 32~40px

## 9. 공통 컴포넌트

### 9-1. 게시글 행 (BoardRow)

```
[NEW] 글 제목 [💬3] [📷]              작성자 닉(IP)   2시간전   조회 124  ❤7
```

- 한 줄 안에 모든 정보
- 좌측: 뱃지 영역 (NEW/HOT/공지/이미지/댓글수) → 제목 → 카테고리 태그(선택)
- 우측: 작성자(IP는 익명만) → 시간 → 조회수 → 추천수
- 배경: 짝수 줄 `--bg-tertiary`, 호버 시 `--bg-secondary`
- 보더: 행 사이 1px 점선 `--border`

### 9-2. 사이드바 위젯 (SidebarCard)

- 폭: 300px (데스크톱)
- 헤더: 위젯 제목(굵게) + 우측 "더보기" 링크 (선택)
- 본문: 리스트 5~10개 항목
- 카드 자체 보더: 1px `--border`, 라운드: 4px
- 위젯 사이 간격: 16px

### 9-3. 뱃지 (Badge)

- 작은 사각 뱃지: 글자 11px, 좌우 패딩 6px, 세로 2px, 라운드 2px
- 색상은 시맨틱 토큰별 (HOT=주황, 공지=노랑, NEW=그린, 호재=빨강, 악재=파랑)

### 9-4. 탭 (Tabs)

- 게시판 내 카테고리 탭, 코인룸 내 (전체/시세/뉴스/공지) 탭
- 비활성: `--text-secondary`, 활성: `--text-primary` + 하단 2px 브랜드 보더
- 호버: `--bg-tertiary`

### 9-5. 페이지네이션

- 게시판 표 하단
- `< 이전 [1] [2] [3] ... [10] 다음 >` 네이버 스타일
- 현재 페이지: 굵게 + 브랜드 컬러
- 하단에 "글쓰기" 버튼 우측 정렬

### 9-6. 글쓰기 버튼 (CTA)

- 헤더 우측 + 게시판 페이지 우상단 + 모바일 FAB 3곳에 노출
- 배경: `--brand-primary`, 텍스트 흰색
- 패딩: 8px 16px, 라운드 4px
- 호버: `--brand-primary-hover`

### 9-7. 검색 바

- 헤더 우측 검색 아이콘 클릭 → 모달/드롭다운으로 전체 사이트 검색
- 입력 시 자동완성 (최근 검색어, 인기 검색어)
- 결과: 게시판/뉴스/공식글 통합 검색

## 10. 인터랙션 상태

| 상태 | 처리 |
|------|------|
| **호버** | 행: `--bg-secondary`, 링크: 색 변화 + 밑줄, 버튼: 어두워짐 |
| **포커스** | 2px `--brand-primary` 외곽선 (접근성 필수) |
| **방문 링크** | 게시판 글 제목은 회색(`--text-secondary`)으로 변환 (네이버 관습) |
| **로딩** | 스켈레톤 (게시판 5줄 회색 박스) |
| **빈 상태** | "아직 글이 없습니다" + 글쓰기 CTA |
| **에러** | 상단 빨강 배너, 본문 유지 |

## 11. 접근성

- 색상 대비: WCAG AA 이상 (텍스트 4.5:1)
- 키보드 탐색: Tab으로 모든 인터랙션 도달 가능
- 스크린리더: 게시판 행에 적절한 aria-label
- 폰트 크기: 최소 12px, 본문 14px 이상
- 호버 의존 금지: 모든 정보는 클릭/포커스로도 도달 가능
