# 디자인 의뢰서 인덱스 (Design Brief)

> 작성일: 2026-05-10
> 목적: Google Stitch에 의뢰할 디자인 시안 요청서 모음.
> 방향성: `docs/PROJECT_DIRECTION.md` (먼저 합의 후 의뢰서 사용)

---

## 사용 방법

1. **먼저** `../PROJECT_DIRECTION.md`를 검토·합의한다.
2. 합의된 후 페이지별로 Stitch에 의뢰한다.
3. 의뢰 시 **반드시 함께 첨부**:
   - 해당 페이지 의뢰서 본문 (예: `01-home.md`)
   - `00-overview.md`의 디자인 시스템 (컬러·타이포·헤더·푸터·공통 컴포넌트)
4. Stitch 결과 시안은 `_received/{페이지번호-페이지명}/`에 저장.
5. 변경 요청사항은 의뢰서 마지막 "다음 단계" 섹션에 누적 기록.

## 의뢰 우선순위 (제안)

1. **00 + 01 (홈)** — 사이트 정체성·톤 결정. 가장 먼저 받기.
2. **02 (게시판 리스트)** — 사이트의 가장 핵심 컴포넌트(BoardRow). 톤 확정 후.
3. **03 (게시글 상세 + 작성)** — 글 읽기·쓰기 경험.
4. **04 (뉴스)** — 게시판 톤 잡힌 후 같은 행 컴포넌트 재사용.
5. **05 (코인룸)** — 모든 컴포넌트가 정해진 후 통합 페이지.

## 시안 검토 체크리스트 (Stitch에서 받은 후)

- [ ] 한국식 색상(빨↑ 파↓) 정확히 적용?
- [ ] 정보 밀도가 충분한가? (한 화면에 보여야 할 글 수)
- [ ] 흰 배경 + 라이트 그레이 사이드바?
- [ ] 글 제목이 가장 두드러지는가?
- [ ] 모바일 레이아웃 작동?
- [ ] 다른 페이지와 시각적 일관성?
- [ ] 헤더/푸터가 공통 디자인 시스템 따르는가?
- [ ] 회피 사항(풀스크린 히어로, 큰 카드, 그라디언트) 안 들어갔는가?
