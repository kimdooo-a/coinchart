# 디자인 의뢰서 — 05. 코인룸 페이지 (BTC 예시)

> **URL 패턴**: `/coin/{symbol}` (예: `/coin/btc`, `/coin/eth`, `/coin/xrp`, `/coin/sol`, `/coin/altcoin`, `/coin/kimp`)
> **목적**: 한 코인에 대한 모든 정보(시세·차트·뉴스·토론·공식글)를 한 페이지에 통합. "이 코인의 모든 것."
> **참고**: 코인판 코인별 게시판, 인베스팅닷컴 코인 페이지, 트레이딩뷰 심볼 페이지
> **중요**: 6개 코인룸 모두 **동일 템플릿**으로 디자인. 코인 데이터·색상·이름만 차이.

---

## 1. 페이지의 한 줄 정의

> "상단 시세·차트 → 탭(전체/시세/뉴스/토론/공지) → 메인 콘텐츠 → 사이드바(관련 정보)."

## 3. 섹션별 명세

### 3-1. 코인 히어로

- **좌측**: 코인 로고 + 이름 + 심볼
  - 로고: 32~40px 크기
  - 이름: 22px 굵게
  - 심볼: `--text-tertiary` 작게
- **가운데**: 미니 라인 차트 (24h, 너비 200~300px, 높이 60px)
  - 상승=빨강, 하락=파랑 (한국식)
  - 단순 라인, 그리드 없음
- **우측**: 가격 정보
  - 현재가: 24~28px 굵게
  - 등락률: ▲/▼ + 색상
  - 24h 거래량 / 시총 / 시총 순위 (작게, 회색)
- **하단 액션 버튼 2개**:
  - `[📊 차트분석 보기 →]`: `/analysis/btc` 또는 `/analysis/btcusdt`로 (기존 페이지)
  - `[✏️ BTC룸에 글쓰기]`: `/board/free/write?coin=BTC`로 (또는 코인룸 전용 게시판)
- 패딩 위아래 24px, 보더 하단 1px

### 3-2. 탭 네비게이션

- 5개 탭: `전체 / 💬 토론 / 📰 뉴스 / 📊 시세·분석 / 📌 공지`
- 활성 탭: 굵게 + 하단 2px 브랜드 보더
- 클릭 시 URL 해시 (`#discussion`) 또는 쿼리스트링

### 3-3. 탭별 콘텐츠

#### "전체" 탭 (기본)

- 3섹션 세로 스택:
  1. **🔥 BTC 인기글 (오늘 TOP 10)**: 게시판 행 컴포넌트, 10줄
  2. **📰 BTC 뉴스 (오늘 10개)**: 뉴스 행 컴포넌트, 10줄
  3. **💬 BTC 토론 (최신 20개)**: 게시판 행 컴포넌트, 20줄

#### "💬 토론" 탭

- BTC 관련 게시글만 모은 표 (자유게시판/시세토론/정보공유에서 `coin_symbol = BTC` 필터)
- 50줄 + 페이지네이션
- 게시판 리스트 페이지(02)와 동일 컴포넌트 재사용

#### "📰 뉴스" 탭

- BTC 관련 뉴스만 모은 표 (`/news?coin=BTC`로 동일 결과)
- 표 50줄 + 페이지네이션
- 뉴스 페이지(04)와 동일 컴포넌트 재사용

#### "📊 시세·분석" 탭

- 차트: TradingView 위젯 또는 기존 차트 컴포넌트 (큰 차트, 600~800px 높이)
- 보조지표 미니 패널: RSI, MACD, BB 등
- 하단 "전체 차트분석 보기" 버튼 → `/analysis/btc` (기존 페이지)

#### "📌 공지" 탭

- BTC 관련 공지·공식 발표만
- 5~10개 행

### 3-4. 사이드바 (우측 300px)

코인 특화 위젯:

#### 3-4-1. 코인 핵심 지표

- 현재가, 24h/7d/30d 변동률
- 24h 고점/저점, 거래량
- 시총, 시총 순위, 유통량, 도미넌스
- 표 형식, 우측 정렬 숫자

#### 3-4-2. 코인 공포·탐욕 (선택)

- 코인별 공포·탐욕 게이지 (BTC FNG는 Alternative.me 직접 사용)
- 다른 코인은 일반 FNG로 대체

#### 3-4-3. 차트분석 시그널 (기존 AI 분석 연동)

- 카드: 시장 상태 / 신호(매수/매도/중립) / 신뢰도 %
- "상세 보기" → `/analysis/btc`

#### 3-4-4. 관련 코인

- BTC: BCH, WBTC, RBTC 등
- ETH: 모든 L2(Arbitrum, Optimism)
- XRP: Stellar(XLM)
- 작은 리스트, 클릭 시 해당 코인룸으로

#### 3-4-5. 코인 캘린더 (이벤트)

- 다음 반감기 (BTC 한정)
- 다음 FOMC, ETF 결정일 등
- 3~5개 항목

#### 3-4-6. 공식글 (블로그)

- 이 코인 관련 공식 분석 글 3개
- 클릭 시 `/blog/{slug}`

## 8. Stitch 의뢰 시 추가 지시

```
페이지 명: 코인룸 (BTC 예시)
타입: 데스크톱 + 모바일
스타일: 인베스팅닷컴 코인 페이지 + 코인판 코인별 게시판의 하이브리드
요점: 한 화면에 시세 / 인기글 / 뉴스 / 토론 / 분석 시그널이 모두 보임
모듈성: 6개 코인룸이 동일 템플릿. 코인 색상·로고·데이터만 다름
한국식: 상승=빨강, 하락=파랑
강조: 시세 영역 + 인기글 영역
회피: 차트가 너무 큰 영역을 차지 (전체 차트는 도구 페이지로 이동)
모바일: 코인 히어로가 전체 화면 절반 이상 안 차지하게
```
