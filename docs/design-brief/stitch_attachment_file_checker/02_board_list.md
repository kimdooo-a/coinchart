# 디자인 의뢰서 — 02. 게시판 리스트 페이지 (자유/시세토론/정보공유)

> **URL 패턴**: `/board/free`, `/board/market`, `/board/info`
> **목적**: 한 게시판의 글 목록을 한 페이지에 50줄 표 형식으로 보여주고, 카테고리·정렬·검색·페이지네이션·글쓰기 진입을 제공.
> **참고**: dcinside 갤러리 리스트, 코인판 자유게시판, 네이버 카페 게시판
> **중요**: 3개 게시판(자유/시세토론/정보공유)은 **동일 템플릿**으로 디자인. 사이드바 위젯과 카테고리 탭만 차이.

---

## 1. 페이지의 한 줄 정의

> "게시판 이름·소개 헤더 + 카테고리 탭 + 50줄 표(번호·제목·작성자·시간·조회·추천) + 페이지네이션 + 우측 사이드바."

## 3. 섹션별 상세 명세

### 3-1. 게시판 헤더

- 좌측: 게시판 이름 (큰 글자, 18~22px) + 한 줄 설명 + 통계
  - 자유게시판: `💬 자유게시판 — 일상·잡담·뉴스 반응을 자유롭게`
  - 시세토론: `📈 시세토론 — 차트·진입가·전략을 함께 나눠요`
  - 정보공유: `📚 정보공유 — 분석글·자료·뉴스 정리`
- 통계: `글 8,432개 · 오늘 124개 · 활성 사용자 234명`
- 우측: (선택) 게시판 RSS 구독 / 공유 아이콘
- 패딩: 위아래 16px, 보더 하단 1px

### 3-2. 카테고리 탭

- 게시판마다 카테고리 다름:
  - 자유: `전체 / 잡담 / 질문 / 후기 / 인증 / 공지`
  - 시세토론: `전체 / 비트코인 / 이더리움 / 알트코인 / 주식 / 분석글`
  - 정보공유: `전체 / 뉴스정리 / 자료 / 분석글 / 거래소 / 가이드`
- 탭 컴포넌트 (00-overview §9-4)
- 활성 탭은 URL 쿼리스트링 (`?cat=question`)

### 3-3. 정렬·검색·글쓰기 바

- 좌측:
  - **정렬 드롭다운**: `최신순 / 인기순(추천) / 댓글많은순 / 조회순`
  - **필터 토글**: `📷 이미지만 / 💬 댓글많음 / 🔥 핫`
  - **검색 입력**: 게시판 내 검색 (제목, 본문, 작성자)
- 우측: **✏ 글쓰기 버튼** (브랜드 컬러)
- 모바일: 검색은 아이콘만, 클릭 시 확장

### 3-4. 게시글 표 (BoardTable)

- **테이블 헤더**: `번호 / 제목 / 작성자 / 시간 / 조회 / 추천`
  - 작은 글자 (12px), `--bg-secondary` 배경, `--text-secondary` 색
- **공지글 영역**: 상단에 1~3개, 배경 `--bg-tertiary`, 번호 칸에 `[공지]` 뱃지, 점선으로 일반글과 구분
- **일반글 영역**: 한 줄 = 한 글, 50줄
- 행 한 줄 구조 (예시):
  ```
  | 8432 | 비트코인 13만 달러 또 갱신... [HOT] [💬87] [📷] | 차트마스터 | 1시간전 | 2,340 | 58 |
  ```
- **번호 칸**: 우측 정렬, 작은 글자, `--text-tertiary`
- **제목 칸**: 좌측 정렬, **글 제목이 가장 강조**, 14px, 호버 시 브랜드 컬러
  - 우측에 작은 뱃지: `[💬N]`(댓글 1+), `[📷]`(이미지 포함), `[HOT]`(자동 핫), `[NEW]`(1시간 이내)
  - 방문한 글은 `--text-secondary`로 변환
- **작성자 칸**: 회원=닉네임, 익명=닉네임 + (IP 앞2옥텟). 회원 닉은 굵게 또는 컬러 (선택)
- **시간 칸**: 24시간 이내는 상대시간(`1시간전`), 그 이후는 `MM-DD`, 작년 이전은 `YYYY-MM-DD`
- **조회·추천 칸**: 우측 정렬, 천 단위 콤마, 1000 이상은 `1.2k` 표기
- 행 간격: 세로 패딩 8~10px (타이트), 행 사이 1px 보더 (점선 가능)
- 호버: 배경 `--bg-secondary`
- 짝수 줄 zebra: `--bg-tertiary` (선택, 디자인 시안에서 결정)

### 3-5. 페이지네이션

- 표 하단 우측 또는 가운데
- 형식: `< 이전 [1] [2] ... [10] 다음 >`
- 현재 페이지: 굵게 + 브랜드 컬러
- 우측 끝에 **글쓰기 버튼** 추가 노출 (CTA 강조)

## 4. 사이드바 (우측 300px)

홈 페이지와 동일한 위젯 구성:
1. 실시간 시세
2. 핫이슈
3. 공포·탐욕 지수
4. 공식글
5. 도구 바로가기

추가:
- **게시판별 통계**: 이 게시판에서 추천 많은 작성자 TOP 5 (선택)
- **이 게시판 인기글 7일**: 별도 위젯

## 5. 모바일 (~767px)

```
[ Header (햄버거) ]
[ 게시판 헤더 (간단) ]
[ 카테고리 탭 (가로 스크롤) ]
[ 정렬·검색 (아이콘으로 압축) ]
[ 게시글 표 (모바일용 압축) ]
   | 제목                    |
   | 작성자  시간 · 댓글 · 추천 |
[ 페이지네이션 ]
[ Footer ]
[ 우하단 ✏️ FAB ]
```

- 모바일에서는 표 컬럼 통합:
  - 1줄: 제목 (+ 뱃지)
  - 2줄: `작성자 · 시간 · 💬N · ❤N · 조회 N`
- 번호·조회·추천 따로 컬럼 없음

## 6. 인터랙션·상태

| 요소 | 상태 | 처리 |
|------|------|------|
| 게시글 행 | 호버 | 배경 변화 |
| 게시글 행 | 클릭 | `/board/free/{post-id}` 이동 |
| 글쓰기 버튼 | 클릭 (회원) | `/board/free/write` 이동 |
| 글쓰기 버튼 | 클릭 (비회원) | 모달: "익명으로 작성" 또는 "로그인" 선택 |
| 카테고리 탭 | 클릭 | URL 쿼리 변경, 표 부분만 리로드 (Soft Navigation) |
| 정렬 변경 | 클릭 | 표 리로드, 페이지 1로 |
| 페이지네이션 | 클릭 | 표 리로드, 스크롤 상단으로 |
| 표 로딩 | - | 스켈레톤 50줄 |

## 7. 빈 상태

- 카테고리에 글 없음: "이 카테고리에 아직 글이 없습니다. 첫 글을 작성해보세요." + CTA
- 검색 결과 없음: "검색 결과가 없습니다. 다른 키워드로 시도해보세요."

## 9. Stitch 의뢰 시 추가 지시

```
페이지 명: 게시판 리스트 (자유게시판)
타입: 데스크톱 + 모바일
스타일: dcinside 갤러리 리스트 + 네이버 카페 게시판의 정보 밀도
밀도: 1080p에 50줄 모두 보일 정도로 타이트하게 (행 높이 약 36~40px)
회피: 카드형 게시글 표시, 그림자, 큰 라운드
강조: 글 제목이 가장 두드러지게 (14px, 호버 시 브랜드 컬러)
한국식: 빨강↑ 파랑↓ (시세 위젯에서)
3개 동일: 자유/시세토론/정보공유 동일 템플릿, 카테고리 탭만 다름
```

## 10. 변형 (Variants)

3개 게시판은 디자인 시안 **1개**만 받고, 다음 차이만 적용:

| 게시판 | 헤더 아이콘 | 헤더 텍스트 | 카테고리 탭 |
|--------|----------|----------|-----------|
| 자유 (`/board/free`) | 💬 | 자유게시판 | 잡담/질문/후기/인증/공지 |
| 시세토론 (`/board/market`) | 📈 | 시세토론 | BTC/ETH/알트/주식/분석 |
| 정보공유 (`/board/info`) | 📚 | 정보공유 | 뉴스정리/자료/분석/거래소/가이드 |
