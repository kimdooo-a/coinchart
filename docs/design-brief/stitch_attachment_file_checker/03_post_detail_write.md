# 디자인 의뢰서 — 03. 게시글 상세 + 작성 페이지

> **URL 패턴**:
> - 상세: `/board/{slug}/{post-id}` (예: `/board/free/8432`)
> - 작성: `/board/{slug}/write`
> - 수정: `/board/{slug}/{post-id}/edit`
> **목적**: 글 본문을 잘 읽히게 보여주고 댓글·추천·작성을 쉽게 처리.
> **참고**: 코인판 게시글 상세 (단순한 본문 + 활발한 댓글), 네이버 블로그 본문 (잘 정리된 활자), 티스토리 댓글 영역
> **두 페이지를 한 의뢰서에 묶는 이유**: 동일 컴포넌트(에디터, 댓글, 본문 영역)를 공유하므로 동일 톤으로 디자인.

### A-2. 섹션별 명세

#### A-2-1. 게시글 헤더

- **상단 라인**: 뱃지(HOT/공지 등) + 카테고리 태그(작은 사각)
- **제목**: 22~26px 굵게, 줄바꿈 허용 (긴 제목은 2줄까지)
- **메타 라인**: 작성자(닉+IP) | 작성일시 | 카테고리 | 조회수
- **우측 액션**: 수정/삭제(본인 또는 익명 비번 일치 시), 공유 아이콘
- 보더 하단 1px

#### A-2-2. 본문 영역

- **너비**: 메인 영역 760px 그대로 사용
- **타이포**: 본문 16px, 줄높이 1.7, `--text-primary`
- **단락 간격**: 16px
- **이미지**: 본문 너비에 맞춰 자동 축소, 클릭 시 확대 모달
- **인용**: 좌측 4px 보더, `--bg-secondary` 배경, 들여쓰기 16px
- **코드 블록**: `--bg-secondary` 배경, 12px 패딩, 모노 폰트, 우상단 복사 버튼
- **링크**: `--text-link` 색 + 밑줄, 외부 링크는 작은 ↗ 아이콘
- **YouTube 임베드**: 16:9 비율 박스
- **표**: 보더 1px `--border`, 헤더 `--bg-secondary`
- 패딩: 위아래 32px

#### A-2-3. 추천·공유·신고 바

- 가운데 정렬
- **추천/비추천**: 큰 버튼 2개 (👍 추천 N / 👎 비추 N)
  - 클릭 시 카운트 증가 + 색 변화
  - 비회원은 IP 1회 제한, 회원은 user_id 1회 제한
- **공유**: 클릭 시 드롭다운 (URL 복사, 카카오, X(트위터), 페이스북)
- **스크랩**: 회원만, 마이페이지에 저장
- **신고**: 모달로 사유 선택

#### A-2-4. 태그

- 본문 하단에 작은 태그 칩 (`#비트코인`, `#ATH`)
- 클릭 시 같은 태그 글 목록으로

#### A-2-5. 댓글 영역

**댓글 작성 박스 (상단)**:
- 비회원: 닉네임/비번 필드 + 본문 textarea + [등록]
- 회원: 본문 textarea만 + [등록]
- 텍스트 박스: 1px 보더, 라운드 4px, 패딩 12px, 4줄 기본 높이
- 우측 글자수 카운터 (선택)

**댓글 정렬 탭**: `최신순 / 추천순 / 등록순` (작은 텍스트 링크)

**댓글 1개**:
- 1줄: `작성자(IP) | 시간 | (수정됨)`
- 2~N줄: 본문 (줄바꿈 허용)
- 마지막: `[👍 N] [답글] [신고] [수정] [삭제]`
- 좌측 정렬, 보더 하단 1px 점선

**대댓글**:
- 좌측 들여쓰기 24~32px (또는 좌측 보더 2px)
- 깊이는 최대 2단계 (대대댓글까지)
- 디자인은 부모 댓글과 동일하되 살짝 작은 글자

**삭제된 댓글**: 회색 박스 "삭제된 댓글입니다"

**페이지네이션**: 댓글 50개씩, 하단에 "더 보기" 버튼

#### A-2-6. 이전글/다음글

- 같은 게시판 + 같은 카테고리 기준
- 좌측 ◀ 이전: 글 제목 (작게), 우측 ▶ 다음: 동일
- 클릭 시 해당 글로

#### A-2-7. 같은 게시판의 글 미니 표

- 10줄 (게시판 리스트 행 컴포넌트 재사용, 더 작은 크기)
- 하단에 "게시판 더 보기" 링크

### A-3. 사이드바 (우측 300px)

홈/리스트와 동일 위젯 + 추가:
- **관련 글**: 같은 카테고리 / 같은 작성자 / 비슷한 태그 (5개)

### A-4. 모바일

```
[ Header ]
[ 브레드크럼 (작게) ]
[ 게시글 헤더 ]
[ 게시글 본문 (가로 100%) ]
[ 추천·공유 바 (가로 stretch) ]
[ 태그 ]
[ 댓글 작성 박스 ]
[ 댓글 정렬 ]
[ 댓글 리스트 ]
[ 이전/다음 ]
[ 같은 게시판 미니 표 ]
[ 사이드바 위젯 (메인 영역으로 스택) ]
[ Footer ]
```

### B-2. 섹션별 명세

#### B-2-1. 게시판/카테고리 선택

- 드롭다운 2개
- URL 진입 시 기본값: 진입한 게시판
- 카테고리는 게시판에 따라 동적 변경

#### B-2-2. 작성자 정보 (비회원만 표시)

- 닉네임: 2~12자 한글/영문/숫자
- 비밀번호: 4자 이상, 작성 후 수정·삭제 시 검증
- 회원 로그인 시 이 영역 자동 숨김 + 작성자 표시

#### B-2-3. 제목

- 단일 입력 필드, 100자 제한
- 글자수 카운터 우측 (작게)
- 보더 1px, 라운드 4px, 패딩 12px

#### B-2-4. 에디터

- **이미 구현됨**: TipTap 에디터 (`components/Blog/editor/BlogEditor.tsx`)
- **재사용 가능**: 블로그 에디터를 게시판에서도 사용
- **툴바 압축**: 블로그용보다 단순한 툴바 권장 (선택)
  - 필수: B/I/U/S, H1/H2, 목록, 인용, 링크, 이미지, 코드
  - 선택: 표, YouTube, 색상, 정렬, HTML 보기
- **자동저장**: 3초 디바운스, localStorage (블로그 에디터에 이미 구현)
- **이미지 드래그앤드롭**: O
- **최소 높이**: 400px, 자동 확장

#### B-2-5. 태그

- 입력 + 엔터/콤마로 추가
- 최대 10개
- 클릭으로 삭제

#### B-2-6. 옵션

- `[ ] 익명으로 작성`: 회원이라도 익명으로 (다음 단계에서 결정 가능)
- `[ ] 댓글 알림 받기`: 회원만, 새 댓글 시 알림 (v2.1)

#### B-2-7. 미리보기

- 토글 버튼
- 작성 중인 본문을 실제 게시글 상세 레이아웃으로 미리 보여줌

#### B-2-8. 액션 버튼

- **임시저장**: localStorage (블로그 에디터에 이미 있음)
- **취소**: 모달 확인 → 게시판 리스트로
- **등록**: 검증 후 POST → 상세 페이지로 리다이렉트

### B-3. 사이드바

작성 페이지에서는 사이드바 **숨김 또는 매우 좁게**. 본문에 집중하도록 메인 영역을 약 80%로 확장.

또는 우측에 작성 가이드 (글쓰기 팁, 금지 행위, 마크다운 단축키 안내) 박스를 좁게 표시.

### B-4. 모바일

- 1단 레이아웃
- 에디터 툴바 가로 스크롤
- 키보드 영역 고려한 하단 패딩

## C. 인터랙션·상태

| 요소 | 상태 | 처리 |
|------|------|------|
| 추천 | 클릭 (회원) | 카운트 +1, 버튼 색 변화, 재클릭 시 취소 |
| 추천 | 클릭 (비회원) | IP 기반 1회 제한, 안내 토스트 |
| 댓글 작성 | 등록 | 폼 초기화, 새 댓글이 위에 추가, 부드러운 등장 애니메이션 |
| 댓글 답글 | 클릭 | 해당 댓글 아래 작성 박스 슬라이드 |
| 본문 이미지 | 클릭 | 라이트박스 모달 |
| 작성 중 | 자동저장 | 우상단 "임시저장됨 12:34" 텍스트 |
| 작성 중 | 페이지 이탈 | "작성 중인 내용이 있습니다. 정말 떠나시겠습니까?" |
| 등록 | 성공 | 토스트 + 상세 페이지로 리다이렉트 |
| 등록 | 실패 | 폼 유지 + 에러 메시지 상단 표시 |
| 신고 | 클릭 | 사유 선택 모달 |

## F. Stitch 의뢰 시 추가 지시

```
페이지 명: 게시글 상세 + 글쓰기 (2개 화면)
타입: 데스크톱 + 모바일
스타일: 코인판 게시글 + 네이버 블로그 본문 가독성 + 티스토리 댓글
강조: 본문 가독성 (16px, 줄높이 1.7), 댓글 활발한 표현
회피: 댓글이 답답하게 보이는 좁은 영역, 추천 버튼이 묻히는 디자인
한국식: 빨/파 (사이드바 시세에서)
에디터: TipTap 기반 (이미 구현됨), 의뢰 시 "워드 비슷한 툴바 + 본문 영역 400px"로 단순화 가능
모바일: 키보드 올라왔을 때 작성 영역 잘림 없게
```
