## 상태 전이 표

| 현재 상태 | 조건 | 다음 상태 |
|-----------|------|-----------|
| START | URL 입력 | navigate |
| navigate | HTTP 200 | evaluate_structure |
| navigate | HTTP 4xx/5xx | record_failure |
| navigate | 타임아웃 | record_failure |
| evaluate_structure | 데이터 존재 | check_blocking |
| evaluate_structure | 데이터 없음 | record_failure |
| check_blocking | 차단 없음 | **SUCCESS** |
| check_blocking | 차단 감지 | take_screenshot |
| take_screenshot | 완료 | record_failure |
| record_failure | 시도 < 3 | search_alternative |
| record_failure | 시도 >= 3 | **FINAL_FAILURE** |
| search_alternative | URL 발견 | navigate (새 URL) |
| search_alternative | URL 없음 | **FINAL_FAILURE** |

## 결정 분기점 요약

### 분기점 1: HTTP 상태
```
HTTP 200 → 계속 진행
HTTP 4xx/5xx → 실패 기록 → 대체 검색
```

### 분기점 2: 데이터 존재
```
데이터 있음 (rows > 0 || lists > 5) → 차단 패턴 검사
데이터 없음 → 실패 기록 → 대체 검색
```

### 분기점 3: 차단 패턴
```
차단 없음 → ✅ 성공
차단 감지 → 스크린샷 → 실패 기록 → 대체 검색
```

### 분기점 4: 재시도 횟수
```
시도 < 3 → Tavily 검색 → 새 URL로 재시도
시도 >= 3 → ⛔ 최종 실패 → 종료
```

## 성공/실패 출력 예시

### 성공 출력
```
✅ 크롤링 가능 확인
- URL: https://data.go.kr/example
- 페이지 타입: 정적 HTML
- 데이터 구조: <table> 태그 (25개 행)
- 권장 방법: Requests + BeautifulSoup4
- 추가 참고: 페이지네이션 있음 (10페이지)
```

### 실패 출력 (재시도 중)
```
❌ 접근 불가: https://example.com
이유: Cloudflare 차단
스크린샷: blocked-site-evidence.png

🔄 다른 사이트 찾는 중... (시도 1/3)
```

### 최종 실패 출력
```
⛔ 모든 대체 사이트 접근 실패

📋 차단된 사이트 목록:
1. https://site1.com - Cloudflare 차단 (2024-12-29T10:30:00Z)
2. https://site2.com - 로그인 필요 (2024-12-29T10:31:00Z)
3. https://site3.com - CAPTCHA 필요 (2024-12-29T10:32:00Z)

💡 권장 조치:
- 수동으로 공공데이터포털(data.go.kr) 검색
- API 키 발급 후 재시도
- 다른 데이터 소스 검토
```
