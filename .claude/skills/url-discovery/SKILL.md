# URL Discovery Skill

Tavily MCP를 사용하여 크롤링 대상 URL을 찾는 전문 skill입니다.

## Tavily MCP 사용법

**도구명**: `mcp__tavily-remote__tavily_search`

**파라미터**:
```json
{
  "query": "검색어",
  "search_depth": "advanced",
  "max_results": 10,
  "topic": "general"
}
```

**응답 형식**: `[{"url": "...", "title": "...", "content": "..."}]`

---

## 검색 전략 (3단계)

### 1차 검색: 기본 키워드
- **검색어**: 사용자 요청 키워드 그대로
- **설정**: `search_depth="advanced"`, `max_results=10`

### 2차 검색: 구체화 (1차 실패 시)
검색어 변경 패턴:
- `[키워드] + [데이터 제공 기관]`
  - 예: "서울 와이파이" → "서울 열린데이터광장 와이파이"
- `[키워드] + [플랫폼명]`
  - 예: "부산 관광" → "부산 공공데이터 관광"

### 3차 검색: 대안 접근 (2차 실패 시)
검색어 변경 패턴:
- `[키워드] API`
- `공공데이터포털 [키워드]`
- 동의어 사용:
  - 예: "와이파이" → "무선랜", "WiFi"

---

## URL 선정 기준

**우선순위**:
| 순위 | 대상 | 도메인 예시 |
|------|------|------------|
| 1 | 공식 공공데이터 포털 | `.go.kr`, `data.go.kr` |
| 2 | 정부/지자체 공식 사이트 | `seoul.go.kr`, `busan.go.kr` |
| 3 | 신뢰할 수 있는 공공기관/공기업 | `kdata.or.kr`, `kostat.go.kr` |

**제외 대상**:
- 개인 블로그
- 카페
- 뉴스 기사

---

## 출력 규칙

### 성공 시
```
✅ URL 발견: [URL]
```
(한 줄로 출력)

### 실패 시
```
❌ URL을 찾을 수 없습니다.

다음 방법을 시도해 보세요:
1. 공공데이터포털(data.go.kr)에서 해당 데이터 검색
2. "API 문서" 키워드 추가해서 재검색
3. 관련 정부 부처 웹사이트 확인
4. 직접 URL을 제공해주시면 바로 코드 생성하겠습니다.
```

## 금지 사항

- URL을 추측해서 만들지 말 것
- 블로그/카페/기사 URL을 "공식 URL"로 반환하지 말 것
